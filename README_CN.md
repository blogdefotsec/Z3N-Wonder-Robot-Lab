Z3N的妙妙机器人工具箱，包含了Z3N在调试Unitree机器人过程中使用的神秘妙妙便利工具。

本仓库随缘更新，有BUG随时反馈Issues。周末会看。

## 内容物

### H2 Teaching Mode

H2上肢示教模式。

支持将H2机器人转换为示教模式，录制或者播放一段示教动作。

播放示教动作的时候可以走动。示教动作包含头部动作。

利用ArmSDK制作的小工具。可用于简单DEMO（如写毛笔字，手势舞、打鼓等）。

H2上肢很重，用的时候注意安全！

### unitree sdk2 isaac bridge

Unitree SDK2与Isaac Lab的桥接工具，支持通过/lowcmd直接控制Issac Lab中的机器人。

目前支持Unitree RL Lab中的所有机器人。支持使用吊架把机器人吊起来。
